📊 Đồ án môn học: Phân tích dữ liệu
🧩 Giới thiệu

Đồ án được thực hiện trong khuôn khổ môn Phân tích dữ liệu, nhằm áp dụng các kiến thức đã học về xử lý, trực quan hóa và phân tích dữ liệu thực tế bằng các công cụ Python (pandas, matplotlib, seaborn, v.v...).

🎯 Mục tiêu

Hiểu và áp dụng quy trình phân tích dữ liệu (Data Analysis Process).

Làm sạch, tiền xử lý và khám phá dữ liệu (EDA - Exploratory Data Analysis).

Trực quan hóa dữ liệu để tìm ra các mẫu, xu hướng và mối quan hệ.

Đưa ra nhận xét và kết luận dựa trên kết quả phân tích.

🧠 Nội dung chính

Thu thập dữ liệu: Dữ liệu được lấy từ [nguồn dữ liệu thực tế hoặc mô phỏng].

Tiền xử lý: Làm sạch dữ liệu, xử lý giá trị thiếu và dữ liệu ngoại lai.

Phân tích khám phá (EDA): Sử dụng thống kê mô tả và biểu đồ trực quan.

Trực quan hóa dữ liệu: Dùng các biểu đồ như Histogram, Boxplot, Heatmap, Scatter Plot,...

Kết luận: Rút ra insight và đề xuất cải thiện.
